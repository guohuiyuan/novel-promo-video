# 设计契约：旧报纸 + 铅字 + 套红

世界观：1996—1997 年中国内地旧报纸。纸负责底，墨负责字，朱红只给「决定性的那一笔」。夜蓝只在沼泽夜晚出现，珠光只给宝物，除此之外没有第六种颜色。

## 色值（`spec.ts` 的 `C`）

| 角色 | 色值 | 用在哪 |
|---|---|---|
| paper | `#EDE4D0` | 整片底色 |
| paperDeep | `#DED2B6` | 大号页码、照片底 |
| paperEdge | `#C9BB9B` | 细框、分隔线 |
| ink | `#191713` | 标题、正文 |
| inkSoft | `#4C463A` | 次级正文 |
| inkFaint | `#8B8271` | 报头、页脚、标签 |
| vermilion | `#B03A2E` | 朱印、台词引号、关键数字、Kicker 编号 |
| night / nightSoft | `#1A212A` / `#2A3542` | 开篇沼泽夜 |
| gold | `#B98B45` | 珠光/宝物，只在一处出现 |

字体三体，正好对应铅印的三种活字：黑体（标题/数字/标签）、宋体（正文/叙述）、楷体（台词/引文）。`Windows` 自带 SimHei / SimSun / KaiTi，不用下载字体。

## 版式套件（`lib/print.tsx`）

| 组件 | 干什么 | 规矩 |
|---|---|---|
| `Sheet` | 纸 + 报头 + 页脚 + 内框 | `since` 让书眉跟着换页擦入，不在切点跳 |
| `Imprint` | 逐字压印 | 字从 0.94 抬起、落到位；不用弹跳、不用泛白渐显 |
| `Line` | 整行滑入 | 长句用，逐字太碎 |
| `Rule` / `Kicker` | 横线 / 小标签 | 黑体，字距拉开 |
| `Stamp` | 朱印 | **唯一允许过冲的动作**（0.05），过冲来自物理冲击 |
| `Photo` | 3:4 档案照 | `objectPosition: 50% 22%` 保脸；彩色只留 0.12 网点；6 秒推近 2% |
| `Quote` | 台词 | 楷体 + 朱红竖线 + `「」`；`\n` 手动断行 |
| `Stat` | 数字 + 标签 | 数字交给画面，不念 |
| `Page` / `Wipe` | 硬边横向擦除 | 0.26s / 0.3s，**没有淡入淡出** |
| `leave()` | 出场向右退 | 配合下一页擦除，读起来像翻页 |

## 动效（`lib/motion.tsx`）

- 每个镜头是帧号的纯函数；只用 `useTime()` 绝对秒；不用 `<Sequence>`
- `EASE.*` 用精确 expo：Remotion 自带 `Easing.exp` 在 0 点约 0.0005，会泄漏隐藏层
- `prog(t, start, dur, ease)` 全部 clamp 到 0..1
- 切点落在句子之间，不在句中。全片是「读」的节奏，不是「跳」的节奏

## 换风格

只改 `spec.ts` 的 `C` / `FONT` / `SAFE`，场景与 lib 不写死颜色。要换到非「报纸」题材（科技 / 手绘 / 黑底），重写 `print.tsx` 一组组件即可，`data.ts` 与全部脚本不用动。
