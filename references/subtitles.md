# 字幕：照 rec2video，但抬一点

规格来自 `github.com/guohuiyuan/rec2video` 的 `references/subtitles.md`，在 `mk_subs.py` 里落地。

## 样式（ASS）

| 项 | 旁白 `Narration` | 台词 `Line` |
|---|---|---|
| 字体 | Microsoft YaHei | Microsoft YaHei |
| 字号 | 46 | 48 |
| 颜色 | `&H00FFFFFF` 纯白 | 同 |
| 描边 | 3.4，黑 `&H00000000` | 同 |
| 阴影 | 1.8，`&H80000000` | 同 |
| 字距 | 0.6 | 1.4 |
| MarginV | **116** | 114 |

rec2video 原版 MarginV 是 46。这片子底部有一条铅印页脚（页脚线 974，基线 1002），照抄会正好压在「全书 290 章 · 111 万字」上。抬到 116 后字幕底边约 964，离页脚线还有 10px，也不碰女主页的结局行（底约 880）。

**字号别超过 46。** 25 字的长行在 46px 时左缘到 x≈385，会压到左图页照片的右缘（410）。降到 42px 才安全——如果某本书的长句特别多，把 `mk_subs.py` 的 `HEAD` 里 Narration 字号改 42。

## 断句

1. 先按 `，。！？；：、` 断成碎片
2. 超长单句在 `maxlen` 内优先找标点切
3. 相邻碎片加起来 ≤ `maxlen` 就合并；`STRONG = 。！？；…—` 是强断点，不往前并
4. ≤3 字的碎片尽量并回前一行，避免字幕闪一下
5. 行末的 `，。；：、` 去掉——停顿由时间表达，不靠标点
6. 台词给 `maxlen + 4` 的宽限，别把一句引语拆成两段

时间按字数权重分，标点算 0.45 字。最后一句往气口里多留 0.24s，避免话音刚落字就没了。淡入淡出 `\fad(70,70)`。

## 口播 ≠ 字幕

旁白念「一百一十一万字」顺口，字幕写「111 万字」一眼能读。`mk_subs.py` 里 `NUM` 对照表只作用于字幕，不碰 `script.json` 和配音。做新书时按书里的数补条目：

```python
NUM = [
    ("一百一十一万字", "111 万字"), ("二百九十章", "290 章"),
    ("三十五岁", "35 岁"), ("两年", "2 年"), ...
]
# 长的排在前面，否则「一百一十一万」会先被「十一万」截掉
```

数字两侧自动补空格：`他失踪2 年` → `他失踪 2 年`，`35岁的女人` → `35 岁的女人`。

## 输出与烧录

`subs` 一次出两份：`design/subs.ass`（烧录用）和 `design/subs.srt`（投稿外挂）。Windows 下 ffmpeg 的 fontconfig 直接认 SimHei / Microsoft YaHei，不需要额外装字体。

```bash
ffmpeg -y -i out/video-mute.mp4 -i audio/mix.wav -vf "ass=design/subs.ass" ...
```

字幕是硬字幕：烧进画面，投稿时不必再传 ass；srt 是给平台 CC 用的备选。

## 验收

从成片抽 5 帧（开篇、男主页、女主左图页、女主右图页、片尾）看字幕：

- 白字在浅色纸面上是否清晰（靠黑描边）
- 是否压到页脚线或正文
- 长行是否顶到照片
- 台词字幕与上方 Quote 区是否「同一句话出现两次」——画面上已有整句台词时，字幕仍保留，因为观众未必同时读画面；但字号/颜色要能区分（画面楷体墨字、字幕白色黑体）
