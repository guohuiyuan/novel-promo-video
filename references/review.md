# 静帧评审清单

整片渲染一轮 20–40 分钟。渲之前，用 `still` 把关键帧全看一遍；每处问题改完再确认。

## 必看帧

| 秒数 | 看什么 |
|---|---|
| 2 / 8 | 书讯页：竖排报眼是否落在框内、评分表与下方引文是否相撞 |
| 22 / 35 / 42 | 简介三页：清单数字、印章与数字、双栏与下方两行字 |
| 45 / 50 | 排雷页：八类分布表是否压页脚、最重那条的三条事实 |
| 90 / 143 | 男主页：五个字段是否齐全、大号 `00` 是否压字 |
| 170 / 205 / 245 / 395 | 女主页（左图/右图各取）：台词、姓名、身份、外貌、性格、纯洁度、结局 |
| 700 / 730 | 收尾：数字条、片尾标版、`完` 印是否压 endLine |

秒数只是示例：按 `timeline.ts` 的 `CUT` 与 `WOMEN[i].start + narrDur*0.8` 换算。

## 每帧逐项查

1. **文字溢出**：台词自动折成三行，第三行压到下一栏（踩过：杜宛若 24 字台词，`了。` 压到结局行）
   - 修法：`data.ts` 里用 `\n` 手动断两行；必要时给 `Quote` 加 `quoteSize`、加宽 `w`
2. **字段相撞**：身份 / 外貌 / 性格 / 纯洁度 / 结局 的 y 间距 ≥ 60px
3. **页脚**：任何内容不要越过 y=974；女主页结局行底约 880，留有余量
4. **照片遮挡**：左图页照片右缘 410，字幕长行左缘不要小于 420；右图页文字右缘不要大于 1510
5. **大字页码**：230px 的浅纸色页码是填白用的，不能压到正文（左图页放右侧、右图页不放）
6. **印章**：`Stamp` 是唯一允许过冲的动效；只能压在留白处，不能压文字
7. **转场**：切点前后 0.05s 会看到「空纸页」——`Page` 只擦内容、`Sheet` 背景不擦，观感等同翻页起手，正常
8. **留白**：某页下半页空一大片就补一条书评原话或字段，别让纸面死掉

## 成片抽帧复查

渲完 + 烧完字幕，从**成片**（不是静帧）再抽 5 帧：

- 字幕是否出现、位置对不对、有没有压到照片或页脚
- 台词字幕与画面 Quote 区是否重复得刺眼
- 片尾字幕是否已淡出

```bash
for t in 8.5 146 300 540 735; do
  ffmpeg -y -loglevel error -ss $t -i "out/<名字>-推书.mp4" -frames:v 1 .tmp/f$t.png
done
```

## 动效自检（可选）

motion-skill 的 `scripts/check.sh` 能出 12 格联系表与逐 0.5s 帧差曲线，用来找「计划外的运动尖峰」和「过长的静止段」。它假设有 `scripts/cues.json` 与 loop 片，本项目没有，所以模板里没带；需要时从原 skill 复制并删掉 loop seam 与 cues 相关段落。

## 声音自检

分段量音量，确认没有「某段突然没了」：

```bash
for seg in "0 10" "120 10" "300 10" "735 5"; do
  set -- $seg
  ffmpeg -hide_banner -ss $1 -t $2 -i "out/<名字>-推书.mp4" \
    -af volumedetect -f null - 2>&1 | grep -E "mean_volume|max_volume"
done
```

各段 mean 应在同一量级（−20 ~ −25 dB）；只有片尾淡出段明显低。
